# 基于 Flowable 的企业固定资产审批系统

> 无锡太湖学院本科毕业设计（论文）配套工程源码  
> **题目**：基于 Flowable 的企业固定资产审批系统的设计与实现

---

## 一、项目简介

针对中小型企业固定资产管理中“手工台账易错、审批进度不透明、审批规则与业务代码强耦合”等痛点，本系统基于 **Spring Boot 3 + Flowable 7 + Vue 3** 构建了一套前后端分离的固定资产全生命周期审批与管控平台，覆盖 **采购申购 → 多级审批 → 入库建档 → 领用借还 → 报修盘点 → 报废归档** 完整闭环。

---

## 二、技术栈

| 端别 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **后端** | Java 17 + Spring Boot 3.3.5 | 后端 Web 服务框架 |
| **工作流** | Flowable 7.0.1 (BPMN 2.0) | 审批流程定义、流转、网关分支与历史追溯 |
| **持久层** | MyBatis-Plus 3.5.7 + MySQL | 数据库交互、逻辑软删除与分页查询 |
| **安全** | 服务端 Token 拦截器 + BCrypt | 身份认证、接口级 RBAC 权限校验、密码哈希存储 |
| **前端** | Vue 3 + Vite + Element Plus | 前后端分离管理后台界面（Liquid Glass + Bento 风格） |
| **可视化** | ECharts 5 + bpmn-js + JsBarcode + QRCode | 数据看板图表、流程图在线设计与进度高亮、条形码/二维码生成 |

## 三、核心功能与亮点

1. **三套 Flowable BPMN 2.0 工作流驱动**
   - **固定资产主流程（`asset_approval_process`）**：部门主管初审 → 金额判断分支（`≥ 5000` 元自动流转财务主管审批，`< 5000` 元跳过财务）→ 资产管理员确认入库/出库/报废。
   - **设备报修流程（`repair_process`）**：员工在线发起设备报修申请 → 资产管理员审核后变更资产状态为维修中。
   - **在用设备借用流程（`peer_borrow_process`）**：支持向占用人发起借用，先由当前使用人本人同意，若设备金额 `> 1000` 元自动加签部门主管审批。
2. **流程可视化设计与运行态高亮**
   - 集成 `bpmn-js`，支持网页端查看/编辑并在线部署新版本流程图；查看申请进度时可高亮显示已完成节点（绿色）与当前待审节点（橙色），配合审批时间轴展示批注记录。
3. **固定资产全生命周期与条码管理**
   - 采购审批通过后自动入库建档，生成唯一时间戳防重资产编码（`FA-yyyyMMddHHmmss-xxx`），前端支持生成 **Code128 条形码与二维码**电子标签及 CSV 台账导出。
   - 明确展示每台设备的**当前使用人**与**所属部门**，支持「我的名下设备」筛选、本人归还、主管/管理员催还提醒及资产盘点对账。
4. **企业级内控与安全设计**
   - **服务端鉴权与越权拦截**：所有业务接口通过 `AuthInterceptor` 校验服务端 Token 与用户角色，严禁前端伪造身份或越权审批/部署流程。
   - **财务数据权限隔离**：仅财务主管与资产管理员可查看公司资产总价值；普通员工与部门主管首页仅展示本人名下设备数量与价值。
   - **不可篡改审计日志**：`sys_log` 记录操作人 `user_id` 与操作详情，仅提供分页检索，不提供删除或清空接口。
   - **逐级密码重置审批**：忘记密码申请按组织层级逐级提交至直系上级审批，防止越级与未授权重置。


## 五、本地运行方式

### 1. 初始化数据库
在 MySQL 中导入 `database/init.sql`（默认库名 `asset_approval`，如需修改账号密码请同步修改 `backend/src/main/resources/application.yml`）。

### 2. 启动后端（JDK 17 + Maven）
```bash
cd backend
mvn spring-boot:run
```
启动成功后后端监听 `http://localhost:8080`，Flowable 会自动建表并部署流程。

### 3. 启动前端（Node.js 18+）
```bash
cd frontend
npm install
npm run dev
```
浏览器访问：`http://localhost:5173`
